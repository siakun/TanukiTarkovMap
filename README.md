> **Escape from Tarkov용 인게임 미니맵 오버레이 툴입니다.<br>스크린샷을 찍으면 좌표를 감지해 현재 위치를 미니맵에 표시합니다.**

게임 위에 항상 떠 있는 창으로 [tarkov-market.com](https://tarkov-market.com/pilot)의 인터랙티브 맵을 띄우고, 인게임 스크린샷에 기록된 좌표로 현재 위치를 실시간 표시합니다. Online은 사이트 지도 위에, Local은 앱에 담긴 지도에 현재 위치와 방향을 표시합니다. 알트탭 없이 단축키 한 번으로 맵을 확인할 수 있습니다.

## 설치

1. [Releases 페이지](https://github.com/siakun/TanukiTarkovMap/releases/latest)에서 최신 Setup 설치 파일(`TanukiTarkovMap-Setup-<버전>-x64.exe`)을 내려받습니다.
2. 실행해 설치하면 이후 업데이트는 자동으로 적용됩니다. 설정에서 자동 업데이트를 끄거나 원하는 버전으로 되돌릴 수도 있습니다.

설치 없이 쓰고 싶다면 같은 페이지의 포터블 버전(`TanukiTarkovMap-Portable-<버전>-x64.zip`)을 내려받아 압축을 풀고 실행합니다. 포터블은 설치 절차가 없어 아래 요구 사항의 VC++ 재배포 패키지를 직접 깔아야 합니다.

> **요구 사항**: Windows 10/11 (x64), [Microsoft Visual C++ 2015-2022 재배포 패키지(x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)
>
> 재배포 패키지는 내장 브라우저(CefSharp)가 쓰는 런타임입니다. Setup 설치 파일은 없으면 설치 과정에서 알아서 깔아 주므로 따로 준비할 것이 없고, 포터블만 직접 설치가 필요합니다. 없이 실행하면 `CefSharp.Core.Runtime.dll`을 불러오지 못했다는 오류로 앱이 시작하지 않습니다.
>
> **안전성**: 게임 메모리를 읽거나 게임 프로세스에 개입하지 않습니다. 이 앱이 읽는 것은 스크린샷 파일명(이미지 내용이 아니라 이름에 담긴 좌표만)과 입장한 맵이 기록된 게임 로그 두 가지뿐이며, 게임 파일을 수정하지 않습니다. 자세한 원리는 [프로젝트 배경](#프로젝트-배경)을 참고하세요.

## 사용법

1. TanukiTarkovMap을 실행합니다. 게임의 스크린샷 폴더는 자동으로 감지되며, 필요하면 설정 창에서 직접 지정할 수 있습니다.
2. 게임을 시작하면 입장한 맵으로 자동 전환됩니다.
3. 게임 중 단축키(기본 `F11`, 설정에서 변경 가능)로 맵 창을 켜고 끕니다. 단축키는 게임이 실행 중이고 게임이나 맵 창에 포커스가 있을 때만 맵 창을 숨기므로, 맵 창이 보이는 동안 다른 프로그램에서는 같은 키를 그대로 쓸 수 있습니다. 숨겨 둔 맵 창은 어느 창에서든 단축키로 다시 띄울 수 있고, 게임을 끄면 저절로 다시 나타납니다(숨기기 제한은 설정의 실험적 기능에서 끌 수 있음).
4. 인게임 스크린샷 키(기본 `PrtScn`)를 누르면 Online이나 Local에 현재 위치와 방향이 갱신됩니다. Online 위치 표시 안내가 나타나면 상단 바에서 Local로 전환해 주세요(상단 바에 보기 모드가 없으면 먼저 설정에서 켭니다).

지도는 기본으로 `Online`으로 엽니다. 설정의 실험적 기능에서 `상단 바에 보기 모드(Online, Local, Origin) 표시`를 켜면 상단 바에서 보기 모드를 고를 수 있습니다. `Online`은 tarkov-market.com을 지도 위주로 정리하고 현재 위치와 방향을 겹쳐 표시합니다. `Local`은 앱에 담긴 지도로 현재 위치와 방향을 표시합니다. `Origin`은 사이트를 앱의 변경 없이 그대로 엽니다. `Origin`에서는 `PMC`/`SCAV`와 `UI 요소 숨기기`가 적용되지 않습니다. 고른 모드는 다음에 실행할 때도 유지되고, 설정을 끄면 다시 `Online`으로 엽니다.

창 표시/숨김 단축키는 미니맵 창 전체를 트레이로 숨기거나 다시 표시하며, 앱을 종료하지 않습니다. 위치 갱신에는 게임의 Screenshot 키를 사용합니다. 한 모니터에서 게임 위에 계속 띄우려면 상단 핀(항상 위)을 켜 주세요.

> **Steam 사용자 주의**: Steam의 `F12` 스크린샷은 Steam 오버레이 기능이라 좌표가 기록되지 않습니다. 반드시 게임 자체 설정(Controls)의 Screenshot 키를 써야 하며, 기본 `PrtScn`이 동작하지 않는다는 보고가 있으니 그 경우 다른 키로 재바인딩하세요.

설정 창에서 단축키, 투명도, UI 표시 여부, 자동 맵 전환, 스크린샷 자동 정리, 업데이트 방식을 바꿀 수 있습니다. 맵 타일이 쌓이는 브라우저 캐시가 얼마나 되는지 확인하고 비우는 것도 같은 창에서 합니다. 문제가 생기거나 건의할 내용이 있으면 [GitHub Issues](https://github.com/siakun/TanukiTarkovMap/issues)에 남겨 주세요.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 맵 오버레이 | 게임 위에 항상 표시되는 인터랙티브 맵 (Always-on-Top) |
| 실시간 위치 추적 | 인게임 스크린샷으로 Online과 Local의 위치와 방향 갱신 |
| 보기 모드 | 상단 바에서 Online(사이트와 위치 및 방향), Local(앱에 담긴 지도와 위치 및 방향), Origin(원본 사이트) 전환 (실험적 기능, 기본 꺼짐. 끄면 Online) |
| 자동 맵 전환 | 게임 로그를 감지해 입장한 맵으로 자동 전환 |
| 전역 단축키 토글 | 단축키(기본 `F11`) 한 번으로 맵 창 표시/숨김, 조합키와 특수키 지원. 숨기기는 게임이나 맵 창에 포커스가 있을 때만 동작(실험적 기능, 기본 켜짐)하고 다시 띄우기는 어느 창에서나 동작 |
| 레이드 집중 모드 | 레이드 중 게임과 같은 모니터에서 마우스가 닿으면 맵 창이 반대편으로 비켜나고, 그때 Alt를 누르면 일시중지되어 조작 가능, 인벤토리를 닫으면 원래 자리로 돌아옴 (실험적 기능, 기본 꺼짐) |
| 투명도 조절 | 상단 바가 숨겨지면 창이 반투명해져 게임 시야 방해를 최소화 |
| UI 정리 | Online에서 웹페이지의 불필요한 요소를 제거해 맵만 표시 |
| 군즈 최근 목격 제보 | PvE 목격 제보의 맵 표시 |
| 레이드 위치 공유 | 같은 파티로 레이드에 들어간 친구와 스크린샷 위치를 주고받아 지도에 함께 표시 (자동 연결) |
| 업데이트 관리 | 새 버전 자동 적용, 자동 업데이트 끄기, 지난 버전으로 되돌리기 |
| 화면 언어 | 기본은 Windows 표시 언어를 따르고, 설정에서 고르면 다시 시작하지 않고 바로 바뀜 |

군즈 최근 목격 제보는 기본적으로 꺼져 있으며, 설정에서 켤 수 있습니다. 군즈는 확률에 따라 스폰하므로 제보와 실제 출현이 다를 수 있습니다.

레이드 위치 공유는 개발자가 운영하는 서버에 자동으로 접속하며, 입력할 값은 없습니다. 같은 파티로 같은 레이드에 들어간 사람끼리 스크린샷 위치를 주고받고, 내 위치와 함께 게임 계정 ID가 서버로 갑니다. 혼자 들어간 레이드는 공유하지 않고, 같은 레이드의 다른 파티는 내 위치를 받지 않습니다. 친구의 이름표는 내 게임의 파티 알림이나 같은 방 파티원이 알려 준 닉네임으로 표시하고, 찾지 못하면 계정 ID 끝 네 자리로 표시합니다. 지도 왼쪽 아래에는 `InRaid: 3p (이름, 이름, 이름)`처럼 나를 포함한 공유 인원과 이름을 표시합니다. 스크린샷 전에도 표시하며 혼자 들어간 레이드, 로컬 PvE, 메뉴나 연결이 끊긴 상태에서는 숨깁니다.

## 프로젝트 배경

Escape from Tarkov은 인게임에서 스크린샷을 찍으면 파일명에 플레이어의 월드 좌표(X, Y, Z)와 카메라 회전값이 함께 기록됩니다. 개발사 Battlestate Games가 버그 리포트용으로 공식 제공하는 기능이며, 게임 메모리나 프로세스에 접근하지 않고 디스크에 저장된 파일만 읽습니다.

```
2026-09-09[14-14]_179.10, 3.29, -717.65_0, 0.70710678, 0, 0.70710678_15.67 (0).png
└ 날짜/시각 ┘     └ 위치 X, Y, Z ┘      └ 카메라 회전(쿼터니언) ┘
```

[tarkov-market.com](https://tarkov-market.com/pilot)의 Pilot 페이지는 이 좌표를 받아 맵 위에 현재 위치를 표시합니다. 다만 브라우저로 여는 웹앱은 구조적 한계가 있습니다. 게임 위에 항상 고정(Always-on-Top)하거나, 창을 반투명하게 만들거나, 전역 단축키로 토글하는 것처럼 운영체제 창을 직접 제어하는 일을 할 수 없습니다. 데스크톱 클라이언트가 필요한 이유가 여기에 있습니다.

이런 도구는 이미 여럿 있습니다. 원조는 tarkov-market.com이 공식 감지하는 [ggdiam/TarkovPilot](https://github.com/ggdiam/TarkovPilot)(.NET Framework, 트레이 전용 헬퍼)이고, 한국 커뮤니티의 [byeong1/Tarkov-Client](https://github.com/byeong1/Tarkov-Client)는 이를 Edge WebView2로 감싸 창 안에 띄웠습니다. 이 프로젝트는 byeong1 버전의 아이디어에서 출발했지만, 웹뷰 엔진을 CefSharp로 교체하고 창 제어, 좌표 동기화, 빌드 파이프라인을 처음부터 다시 설계했습니다.

## 기술적 구현

이 앱은 게임 메모리나 게임 파일에 손대지 않고, 게임이 디스크에 남기는 스크린샷 파일명과 로그만 읽어 동작합니다.

### 1. 스크린샷으로 현재 위치 표시

게임의 스크린샷 폴더를 지켜보다가 새 파일이 생기면 파일 이름에 기록된 좌표와 시선 방향을 읽습니다. 이미지 내용은 열지 않습니다. Online에서는 사이트 지도 위에 앱이 위치 원과 방향 화살표를 직접 겹쳐 그리고, Local에서는 앱에 담긴 지도에 그립니다. 좌표의 높이 값으로 지금 있는 층도 자동으로 고릅니다.

### 2. 사이트 없이도 동작하는 Local 지도

Local은 사이트에 접속하지 않고 앱에 담긴 지도로 지형과 층, 고른 진영의 탈출구, 내 위치와 방향을 보여 줍니다. 사이트의 구조가 바뀌어 Online 표시가 멈추거나 사이트에 접속할 수 없을 때도 레이드에 필요한 정보를 보도록 만든 모드입니다. 앱에 담은 지도는 사이트의 지도 데이터를 변환해 맵과 층마다 사이트 화면과 대조한 것이며, 위치 표시는 설치 파일을 만들 때마다 자동 검사로 확인합니다.

### 3. 게임 로그로 맵 자동 전환

게임은 레이드에 들어갈 때 불러온 맵을 로그 파일에 기록합니다. 앱은 이 로그를 읽어 입장한 맵으로 지도를 바꿉니다. 게임 설치 폴더는 공식 런처와 Steam의 설치 정보에서 자동으로 찾고, 찾지 못하면 설정에서 지정할 수 있습니다. 레이드 도중에 앱을 켰다면 레이드 안에서 스크린샷을 한 번 찍을 때 그 맵으로 맞춰집니다.

### 4. 게임 위에 떠 있는 창

웹페이지는 게임 위에 고정되거나 반투명해질 수 없고, 게임을 하는 동안에는 단축키도 받지 못합니다. 이 앱은 Windows의 창 기능으로 항상 위 고정, 반투명 창, 게임 중에도 동작하는 단축키를 처리하고, 지도는 앱에 내장한 Chromium 브라우저(CefSharp)로 엽니다.

### 5. 지도만 남기는 Online 화면

Online은 tarkov-market.com을 열어 지도를 보는 데 필요 없는 메뉴와 패널을 숨기고, 상단 바에서 고른 진영(PMC, SCAV)의 탈출구를 표시합니다. 이 정리는 앱이 페이지 안에서 스크립트를 실행해 적용하며, Origin은 스크립트를 실행하지 않고 사이트를 그대로 엽니다.

### 6. 레이드 위치 공유

같은 파티로 같은 레이드에 들어간 친구끼리 스크린샷 위치를 주고받아 지도에 함께 표시합니다. 앱은 게임 로그에서 지금 들어간 레이드와 파티를 알아내 개발자가 운영하는 서버의 같은 방에 자동으로 들어가고, 누군가 스크린샷을 찍으면 같은 방의 다른 사람에게 바로 전달합니다. 방은 게임이 파티와 레이드마다 따로 정하는 값으로 나뉘므로 같은 레이드의 다른 파티나 방송 시청자는 들어올 수 없습니다.

서버에는 내 위치와 게임 계정 ID, 닉네임이 전달됩니다. 서버 운영자는 접속 중인 사용자의 IP, 계정 ID와 마지막 위치를 볼 수 있고, 참가 기록(계정 ID, 닉네임, 모드, 맵, 입퇴장 시각)은 통계로 남기지만 IP와 좌표는 저장하지 않습니다. 공유는 부가 기능이므로 서버가 꺼져 있거나 느려도 내 위치 표시는 그대로 동작합니다.

### 7. 자동 업데이트와 버전 선택

설치한 앱은 GitHub Releases에서 새 버전을 확인해 자동으로 업데이트합니다. 새 버전은 앱이 실행된 뒤 내려받아 앱을 종료할 때 적용하며, 바뀐 부분만 받을 수 있으면 그만큼만 받습니다. 새 버전에 문제가 있으면 설정에서 자동 업데이트를 끄고 원하는 지난 버전으로 되돌릴 수 있습니다. 최신이 아닌 버전을 고르면 자동 업데이트도 함께 꺼져 다음 실행에서 최신으로 돌아가지 않습니다. 설정의 실험적 기능에서 베타 받기를 켜면 정식 출시 전 버전도 받습니다.

## 개발 안내

Windows와 .NET 10 SDK 이상이 필요합니다. 앱은 .NET 8에서 실행되며, ViewModel의 partial 속성 생성(`LangVersion=preview`)에 최신 C# 컴파일러를 사용합니다.

```powershell
dotnet build src/TanukiTarkovMap.csproj
dotnet publish src/TanukiTarkovMap.csproj -c Release -r win-x64 --self-contained true -o publish
```

앱 소스는 `src/`에 있습니다. 좌표 계산, 설정, 파일 감시, 위치 공유와 사이트 제어는 `src/packages/`에 포함된 TanukiTarkovMap.Core 패키지가 담당합니다. 프로젝트 파일이 이 패키지의 버전을 고정하고, `src/NuGet.Config`가 Core는 같은 폴더의 `packages/`에서, 나머지 의존성은 NuGet.org에서 복원하므로 별도 계정이나 인증이 필요하지 않습니다. Core DLL은 Obfuscar로 난독화되어 있으며 공개 API와 JSON 계약은 그대로입니다. Releases의 설치 파일은 같은 태그의 소스로 빌드합니다.
