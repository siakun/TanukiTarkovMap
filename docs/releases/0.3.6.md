## 주요 업데이트 내용

- **온라인 지도에서 바라보는 방향이 표시되지 않던 문제 수정**

  사이트 업데이트로 내 위치를 그리는 방식이 변경되어 앱이 방향 삼각형을 붙이던 사이트의 위치 표시가 없어졌습니다. 이제는 앱이 스크린샷 파일명에서 위치와 방향을 읽어 사이트 지도 위에 위치 원과 방향 삼각형을 직접 그립니다. 모양은 Local 지도와 같습니다. 사이트에서는 게임 좌표를 지도 화면의 좌표로 변환하는 계산만 빌립니다. 퀘스트 같은 다른 마커와 층 자동 전환은 이전처럼 사이트의 기능을 사용합니다.

  앱이 더는 사이트의 위치 입력 기능과 내 위치 그리기를 사용하지 않으므로 사이트가 이 두 가지를 다시 변경해도 온라인 지도의 위치 표시는 끊기지 않습니다. 다만 사이트가 좌표 변환을 제공하는 구조를 변경하면 틀린 자리에 그리는 대신 위치를 표시하지 않습니다. 온라인 지도에서 스크린샷을 찍어도 위치가 나타나지 않으면 설정에서 `로컬 맵 사용`을 켜고 상단바에서 `Local`로 전환해 위치를 확인할 수 있습니다. 사이트는 앱이 넘긴 위치를 층을 고르는 데에만 사용하므로 스쿼드 기능처럼 내 위치를 사용하는 다른 사이트 기능에는 반영되지 않습니다.

- **새 스크린샷이 없는데도 위치 원이 커졌다 줄어들던 문제 수정**

  사이트 업데이트 뒤 앱이 위치가 표시됐는지 확인하지 못해 마지막 스크린샷을 2초마다 다시 보냈습니다. 다시 보낼 때마다 위치를 강조하는 애니메이션도 함께 켰으므로 스크린샷을 찍지 않아도 위치 원이 몇 초마다 불규칙하게 커졌다 줄어들었습니다. 이제는 앱이 그린 위치 원이 화면에 보이는지로 표시 여부를 확인하므로 표시된 위치를 다시 보내지 않습니다. 강조 애니메이션은 새 스크린샷을 처음 표시할 때만 켭니다.

- **온라인 지도가 창에 맞춰지지 않고 화면 밖으로 밀려나던 문제 수정**

  사이트가 지도를 그리는 방식을 다시 변경하면서 앱이 지도의 위치와 크기를 읽던 요소가 없어졌습니다. 그래서 지도를 열 때 창에 맞추지 못했고 끌거나 확대할 때 지도를 화면 안에 붙잡아 두지도 못했습니다. 이제는 사이트가 지도를 그릴 때 사용하는 이동, 배율, 회전 값으로 지도의 위치와 크기를 계산합니다.
