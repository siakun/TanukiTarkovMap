## 주요 업데이트 내용

- **일부 PC에서 앱이 시작되지 않던 문제 수정**

  내장 브라우저에 필요한 Visual C++ 런타임이 없는 Windows에서는 `CefSharp.Core.Runtime.dll`을 불러오지 못해 앱이 시작되지 않았습니다. 설치 파일이 필요한 Visual C++ 2015-2022 재배포 패키지를 먼저 설치하도록 바꿨습니다.

## 설치 및 업데이트 안내

- 0.2.5 이하에서 앱이 정상 실행된다면 자동 업데이트로 적용할 수 있습니다.
- 앱이 실행되지 않으면 자동 업데이트도 불가능하므로, 이 릴리스의 `TanukiTarkovMap-Setup-0.2.6-x64.exe`로 재설치해 주세요. 기존 설정과 캐시는 유지됩니다.
- 포터블 버전은 런타임을 자동으로 설치하지 않습니다. 런타임이 없어 실행되지 않는 경우에는 [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)를 직접 설치해 주세요.
