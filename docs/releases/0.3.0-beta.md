## 주요 업데이트 내용

- **사이트 사본으로 지도를 여는 실험적 로컬 모드**

  사이트에 접속할 수 없거나 사이트 변경으로 연동이 끊기면, 레이드 중에 사용할 지도도 영향을 받는 문제가 있었습니다. 일반 브라우저 캐시만으로는 페이지를 다시 열 수 없어, 지도 페이지와 표시에 필요한 자료를 앱에 함께 넣고 그 사본을 읽는 로컬 모드를 추가했습니다. 설정에서 로컬 맵 기능을 켜면 상단바의 `Online` / `Local`로 전환할 수 있습니다.

- **지도를 열고 이동할 때 표시 위치 보완**

  지도를 처음 열 때 창 크기에 맞춰 표시하도록 했습니다. 지도를 화면 밖으로 끌어 빈 공간만 남는 경우에는 지도 영역이 다시 보이도록 위치를 보정합니다.

- **로컬 사본에 필요한 자료 수집 보완**

  지형 파일을 제대로 받지 못한 채 빈 내용으로 저장하거나 폰트와 이미지가 빠지면, 사본이 있어도 지도 화면이 온전히 표시되지 않았습니다. 내용을 받지 못한 자료는 다시 요청하고, 스타일에서 불러오는 폰트와 이미지까지 수집하도록 보완했습니다. 사본만으로 지도와 마커가 그려지는지 확인하는 검사도 추가했습니다.

## 화면과 오류 확인

- 창이 좁을 때 나타나는 모바일 UI도 숨김 설정에 포함했습니다.
- 지도 렌더링 여부와 페이지 오류를 앱 로그에 남겨, 화면이 열리지 않을 때 원인을 확인할 수 있도록 했습니다.

## 로컬 모드 사용 시 참고사항

- 로컬 지도와 정보는 사본을 만든 시점의 내용이며, 사본 갱신은 앱 릴리스에 포함됩니다. 로그인에 의존하는 퀘스트 자동 완료와 스쿼드 기능은 로컬에서 동작하지 않습니다.
- 이 버전의 사본에는 캡처 당시의 모드 하나만 담겨 있으며 PvE/PvP 구분은 지원하지 않습니다.
- 이 버전은 온라인과 로컬의 브라우저 저장 공간을 공유합니다. 온라인을 사용한 뒤 로컬로 전환하면 기존 저장 데이터의 영향으로 위치 표시가 실패할 수 있습니다.
