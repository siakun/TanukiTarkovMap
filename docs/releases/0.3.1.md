## 주요 업데이트 내용

- **온라인 지도에서 스크린샷 위치가 표시되지 않던 문제 수정**

  Lighthouse 등 일부 지도에서는 사이트가 위치를 전달받는 방식이 바뀌어, 앱이 스크린샷을 감지해도 지도에 좌표를 보내지 못했습니다. 페이지에서 지원하는 전달 방식을 확인해 기존 방식과 새 방식에 맞춰 좌표를 보내도록 수정했습니다.

- **앱에 포함된 사본으로 여는 로컬 지도 모드**

  사이트에 접속할 수 없거나 사이트 변경으로 연동이 끊겨도 저장된 지도를 사용할 수 있도록, 지도 페이지와 필요한 자료를 앱에 함께 넣었습니다. 설정의 실험적 기능에서 `로컬 맵 사용`을 켜면 상단바의 `Online` / `Local`로 전환할 수 있습니다. 로컬 화면은 지도와 층 선택, 선택한 진영의 추출구, 현재 위치와 방향을 중심으로 표시합니다.

- **온라인을 사용한 뒤 로컬 모드에서도 위치 표시가 멈추던 문제 수정**

  지도 사본은 앱에 있었지만 온라인과 로컬이 브라우저의 DB와 캐시를 함께 사용하고 있었습니다. 온라인에서 갱신한 데이터가 로컬 사본에 없는 자료를 요청하면 지도 초기화가 실패했습니다. 로컬 모드에 별도의 임시 저장 공간을 마련해 온라인 데이터가 섞이지 않도록 했습니다. 온라인에 저장된 데이터는 유지합니다.

- **새로고침이나 뒤로/앞으로 이동 후 사라진 방향 표시 자동 복구**

  방향 표시를 한 번만 설치하던 방식에서는 페이지가 이동하거나 지도 화면이 교체되면 표시 기능이 사라질 수 있었습니다. 이제 일정 간격과 스크린샷 전달 시점에 기능의 응답을 확인해 필요하면 다시 설치합니다. 화살표 모양을 정하는 스타일이 지워지거나 비활성화된 경우도 복구합니다.

- **지도 로딩과 모드 전환 중 놓친 위치 갱신 보완**

  지도 로딩이 끝나기 전에 위치를 보내면 전달 함수가 실행돼도 마커가 표시되지 않을 수 있었습니다. 이제 실제 위치와 방향 표시가 준비됐는지 확인하고, 그전에는 해당 맵의 최신 스크린샷에 담긴 위치 정보를 보관했다가 다시 전달합니다. 같은 맵에서 모드 전환, 새로고침 또는 지도 재생성으로 마지막 위치가 사라져도 복원하며 이전 페이지의 요청이나 늦게 도착한 응답이 최신 방향을 덮어쓰지 않도록 했습니다.

- **게임 중 단축키로 지도 창을 다시 표시하는 동작 개선**

  항상 위 핀이 꺼져 있으면 창이 게임 뒤에서 표시돼 단축키가 작동하지 않는 것처럼 보일 수 있었습니다. 창을 다시 표시할 때 앞으로 올리면서 게임의 키보드 입력 포커스를 유지하도록 처리했습니다. 최소화된 창도 단축키 첫 입력에 복원하도록 수정했습니다.

## 지도와 설정

- 방향 화살표가 위치 동그라미와 겹치거나 너무 멀리 떨어지지 않도록 간격을 조정하고, 지도 회전도 방향 표시에 반영했습니다.
- 지도를 처음 열 때 창 크기에 맞춰 표시하고, 화면 밖으로 끌어 빈 공간만 남으면 지도 영역이 다시 보이도록 위치를 보정합니다.
- 로컬 지도에서 지형, 폰트와 이미지가 빠지지 않도록 사본 수집을 보완했습니다. 사본만으로 지형과 마커가 표시되는지 확인하는 검사도 추가했습니다.
- 로컬 화면에 남은 패널과 창이 좁을 때 나타나는 모바일 UI에도 `UI 요소 숨기기` 설정을 적용했습니다.
- 지도 렌더링 여부와 페이지 오류를 앱 로그에 남겨, 화면이 열리지 않을 때 원인을 확인할 수 있도록 했습니다.
- 앱의 표시/숨김 단축키와 타르코프의 `Screenshot` 키를 혼동하지 않도록 설정 설명을 보완했습니다. 트레이 숨김과 항상 위 고정의 동작도 함께 안내합니다.
- 군즈 정보는 현재 출현을 보장하는 정보로 오해하지 않도록 `PvE 최근 목격 제보`로 안내하고 실제 출현과 다를 수 있음을 표시했습니다. 새 설정에서는 기본 비활성화하며 기존 사용자가 정한 켜기/끄기 상태는 유지합니다.

## 모드 전환 시 참고사항

- 로컬 지도와 정보는 사본을 만든 시점의 내용입니다. 사본은 앱 릴리스로 갱신하며 로그인에 의존하는 퀘스트 자동 완료와 스쿼드 기능은 로컬에서 동작하지 않습니다.
- 모드를 바꾸면 웹 페이지의 방문 기록과 로컬 페이지 내부 설정이 초기화됩니다. 로컬에 다시 들어갈 때 임시 저장 공간을 새로 마련해 이전 데이터가 섞이지 않게 하기 위한 동작입니다.
- 앱의 진영과 확대 설정은 다시 적용하며, 같은 지도에서 마지막으로 확인한 위치도 복원합니다.

## 확인 범위

- 별도 브라우저 환경에서 위치 전달, 방향 복구와 저장 공간 분리를 확인했습니다. 최종 앱에서 온라인 사용 후 로컬 전환, 로딩 중 스크린샷 촬영, 모드 연속 전환과 실제 게임 중 창 복원 및 포커스 유지는 아직 통합 확인하지 않았습니다.
