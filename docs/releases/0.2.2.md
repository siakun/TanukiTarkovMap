## 주요 업데이트 내용

- **여러 버전을 건너뛸 때도 차등 업데이트 사용**

  원하는 버전을 직접 골라 설치할 때는 적용할 수 있는 차등 패키지가 있어도 전체 파일을 다시 받고 있었습니다. 이제 각 패키지가 요구하는 기준을 확인해, 현재 버전에서 대상 버전까지 실제로 연결할 수 있는 차등 패키지를 이어 적용합니다. 연결 조건이 맞지 않거나 이전 버전으로 내려갈 때는 전체 패키지를 사용합니다.

- **시작이 빠르면 로딩 창 생략**

  앱이 빠르게 켜지는 환경에서는 로딩 창이 잠깐 나타났다 사라져 화면만 깜빡이는 문제가 있었습니다. 시작 시간을 확인해 실제로 로딩이 오래 걸릴 때만 창을 표시하도록 바꿨습니다.
