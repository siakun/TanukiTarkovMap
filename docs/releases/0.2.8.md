## 주요 업데이트 내용

- **스크린샷을 찍을 때마다 지난 맵으로 돌아가던 문제 수정**

  게임이 새 로그 파일에 기록하기 시작해도 앱이 처음 선택한 파일만 읽고 있어, 마지막으로 감지한 옛 맵을 현재 맵으로 계속 사용하고 있었습니다. 최신 로그 파일을 다시 찾아 추적하고, 읽기에 실패해도 다음 주기에 재시도하도록 수정했습니다. 게임을 재시작해 로그 폴더가 바뀌면 이전 맵 정보도 비우도록 했습니다.

- **로그 생성 시점이 달라도 맵 감지 유지**

  서로 다른 로그 파일의 초기 읽기 완료를 한꺼번에 판단해, 한쪽 로그가 늦게 생기면 다른 쪽의 실시간 맵 감지도 건너뛰고 있었습니다. 초기 읽기를 파일별로 판단하고 동시에 읽는 작업이 서로의 진행 상태를 손상시키지 않도록 수정했습니다.

- **레이드 입장 감지와 스크린샷 맵 보정 설정 분리**

  두 동작을 하나로 켜고 끄던 설정을 나눠 각각 선택할 수 있게 했습니다. 예를 들어 레이드에 들어갈 때만 자동으로 맵을 바꾸고, 스크린샷을 찍을 때는 선택한 지도를 유지하는 식으로 사용할 수 있습니다. 메뉴와 은신처에서 찍은 좌표 없는 스크린샷은 맵 보정에 사용하지 않도록 했습니다.
