## 자동 맵 전환 개선

- **스팀판에서 게임 로그를 찾지 못하던 문제 수정**

  스팀판은 일반 설치와 로그 폴더 구조가 다른데, 앱이 한 가지 위치만 확인해 자동 맵 전환이 멈춰 있었습니다. 두 구조를 모두 확인하도록 바꾸고 다른 드라이브의 스팀 라이브러리도 찾도록 보완했습니다. 이전 설치의 레지스트리 정보가 남아 있어도 스팀판 탐지를 막지 않도록 했습니다.

- **맵을 감지해도 지도 화면이 바뀌지 않던 문제 수정**

  로그 파일을 찾는 규칙이 실제 파일명과 맞지 않았으며, 맵을 감지한 뒤에도 이름만 갱신하고 브라우저의 지도 선택으로 연결하지 못하는 경우가 있었습니다. 파일 탐색 규칙을 고치고 감지한 맵을 실제 화면 전환까지 전달하도록 수정했습니다.

- **레이드 도중 앱을 켜도 현재 맵으로 맞추기**

  앱을 늦게 켜면 레이드 진입 로그가 이미 지나가 있어 실시간 감지만으로는 현재 맵을 알리지 못했습니다. 기존 로그에서 마지막으로 감지한 맵을 기억하고, 게임에서 스크린샷을 찍을 때 그 맵으로 화면을 맞추도록 보완했습니다.

## 설정과 표시

- 수동으로 지도를 선택해 사용하려는 경우를 위해 레이드 진입 시 자동 맵 전환을 켜거나 끄는 설정을 추가했습니다.
- 트레이 툴팁의 위치와 닫힘 처리가 어긋나 화면 왼쪽 위에 남던 문제를 수정했습니다. 트레이 구성 요소를 갱신해 Windows 기본 툴팁을 사용하도록 했습니다.
