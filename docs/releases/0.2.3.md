## 스크린샷 위치 연동 수정

- **Pilot v2에 맞춘 위치 전달 방식 변경**

  사이트의 Pilot v2 변경으로, 사이트가 앱에 먼저 연결하던 기존 통신 방식을 더 이상 사용하지 않게 됐습니다. 이 때문에 스크린샷을 찍어도 위치가 지도에 전달되지 않았습니다. 앱이 열린 페이지의 위치 처리 함수를 직접 호출하도록 바꿨으며, 퀘스트 완료 정보도 같은 경로로 전달하도록 했습니다.

- 사용되지 않는 기존 연결 감지와 통신 서버를 제거했습니다. 위치와 퀘스트 정보가 실제 페이지에 전달되는 경로를 기준으로 연동하도록 정리했습니다.
