## 변경 내용

- **업데이트 알림 아이콘의 안내 표시 변경**

  새 버전을 다 받으면 상단바에 초록 다운로드 아이콘이 나타납니다. 이제 이 아이콘에 마우스를 올리면 아이콘 둘레에 둥근 강조가 생기고, 아이콘 바로 아래에 아이콘을 가리키는 "업데이트 준비 완료!" 말풍선이 뜹니다. 이전에는 Windows 기본 툴팁이 마우스 커서 옆에 떴습니다.

  아이콘을 누르면 지금까지와 같이 앱이 다시 시작되며 업데이트가 적용됩니다. 다시 시작하는 동안에는 지도의 위치 표시가 잠시 멈추므로, 레이드가 끝난 뒤에 눌러 주세요. 누르지 않아도 트레이에서 앱을 종료할 때 업데이트가 적용됩니다.
