## 주요 업데이트 내용

- **온라인 지도에서 스크린샷을 찍어도 위치가 바뀌지 않던 문제 수정**

  사이트 업데이트로 앱이 위치를 넘기던 사이트 기능이 사라져, 스크린샷을 감지해도 지도에 위치를 표시하지 못했습니다. 이제는 사이트에 남아 있는 "Where am i" 입력이 파일명을 처리하는 방식 그대로 스크린샷 파일명을 넘겨 위치와 방향을 표시합니다. 새 위치가 화면 밖이나 가장자리에 있으면 그 위치가 보이도록 지도를 옮깁니다.

- **온라인 지도를 열 때 창에 맞춰지지 않고 확대하면 지도가 사라지던 문제 수정**

  사이트가 지도를 그리는 방식을 다시 바꾸면서 앱이 지도의 실제 크기를 재지 못했습니다. 그래서 지도를 처음 열 때 창에 맞추지 못했고, 끌거나 확대할 때 지도를 화면 안에 붙잡아 두지도 못했습니다. 이제 화면에 실제로 그려진 지도를 골라 크기를 잽니다. 끌 때뿐 아니라 마우스 휠로 확대하거나 창 크기를 바꾼 뒤에도 화면 가운데에 지도가 남도록 되돌립니다.

  창이 작아 가장 작게 줄여도 지도가 창보다 큰 경우(Icebreaker 등)에는, 지도를 맞추는 동작이 방금 표시한 현재 위치를 화면 밖으로 밀어내던 문제도 함께 고쳤습니다. 현재 위치가 표시되어 있으면 지도를 맞춘 뒤에도 그 위치가 화면 안에 남습니다.

- **로컬 지도를 앱이 직접 그리는 방식으로 변경 (실험적 기능)**

  로컬 지도는 사이트 페이지를 저장해 둔 사본을 열던 방식이라, 사본을 새로 받으면 사이트의 변경까지 그대로 따라왔습니다. 이제는 사이트의 지도 데이터만 앱에 담고, 앱의 미니맵이 사이트 지도와 같은 모양으로 지형, 층, 선택한 진영의 추출구, 현재 위치와 방향을 그립니다. 사이트 코드를 실행하지 않으므로 이번처럼 사이트가 위치를 넘겨받는 방식을 바꿔도 로컬 지도의 위치 표시는 계속 동작합니다.

  설정에서 `로컬 맵 사용`을 켜면 상단바에서 `Online` / `Local`을 전환할 수 있습니다. 층 선택 패널은 상단바의 `UI 요소 숨기기`를 끄면 나타나고, 층은 스크린샷에 기록된 높이에 맞춰 자동으로 바뀝니다. `로컬 맵 사용` 아래에는 앱에 담긴 지도 데이터의 기준 날짜가 표시되며, 데이터는 앱을 업데이트할 때 함께 갱신됩니다. 퀘스트처럼 사이트에만 있는 기능은 `Online`에서 이용합니다.
