## 주요 업데이트 내용

- **온라인 지도에서 PMC/SCAV 전환이 동작하지 않던 문제 수정**

  상단바의 `PMC`/`SCAV`를 눌러도 지도에 표시되는 탈출구가 달라지지 않았습니다. 사이트는 창 폭이 좁으면 모바일 화면으로 전환하면서 필터 패널을 만들지 않는데, 앱은 그 패널의 필터를 눌러 진영을 전환하고 있었습니다. 그래서 앱 창을 좁게 쓰면 전환이 동작하지 않았습니다. 이제는 필터 패널이 없으면 사이트의 모바일 메뉴로 같은 패널을 잠깐 열어 필터를 누르고 다시 닫습니다. 패널은 화면에 나타나지 않습니다.

- **앱을 다시 켜면 지도에 지난 진영의 탈출구가 남던 문제 수정**

  사이트는 마지막으로 고른 필터를 기억해 두었다가 맵을 열 때 그대로 불러옵니다. 그래서 SCAV를 고른 채 앱을 종료했다가 다시 켜면 상단바는 PMC인데 지도에는 SCAV 탈출구가 표시됐습니다. 이제는 맵을 열 때마다 사이트가 지도 데이터를 받을 때까지 기다렸다가 상단바의 진영으로 맞춥니다. 맵을 연 직후 잠깐은 사이트가 기억한 진영이 보일 수 있고, 앱은 진영을 기억하지 않으므로 항상 PMC로 시작합니다.

- Labs, Labyrinth, Icebreaker처럼 Scav 탈출구가 없는 맵에서 SCAV를 고르면 탈출구가 표시되지 않습니다. 로컬 지도도 같습니다.
