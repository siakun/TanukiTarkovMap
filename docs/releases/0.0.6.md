## 주요 업데이트 내용

- **처음 실행할 때 스크린샷 감지가 시작되지 않던 문제 수정**

  스크린샷 폴더가 아직 없는 상태에서는 감시가 시작되지 않았고, 게임이 나중에 폴더를 만들어도 앱이 이를 알아차리지 못했습니다. 상위 폴더에서 스크린샷 폴더의 생성을 확인한 뒤 파일 감시를 시작하도록 바꿨습니다.

- **업데이트 후 설정이 초기화되던 문제 수정**

  설정 파일을 실행 위치에 따라 찾고 있어, 업데이트로 실행 위치가 바뀌면 저장한 설정을 읽지 못했습니다. 버전별 실행 폴더에 의존하지 않도록 사용자 데이터 안의 고정된 경로에 설정을 저장하도록 변경했습니다.

- 종료할 때 중복으로 실행되던 정리 작업을 없애고 각 서비스의 종료 대기를 조정해, 프로그램이 닫히는 데 걸리는 시간을 줄였습니다.
- 설정 파일을 직접 확인할 때 찾기 쉽도록 개발자 도구에 파일 위치를 표시했습니다.
