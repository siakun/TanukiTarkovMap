## 주요 업데이트 내용

- **`UI 요소 숨기기`가 지도 위에 새로 생긴 UI까지 가림**

  이 설정은 지도를 가리는 사이트의 패널을 하나씩 지정해 숨기고 있었습니다. 그래서 사이트가 지도 위에 가이드 패널이나 출처 줄 같은 UI를 새로 얹으면 설정을 켜도 그대로 보였습니다. 이제는 반대로 지도 그림과 마커, 나침반, 현재 위치 표시, 마커 설명 창처럼 지도를 이루는 요소만 남기고 나머지를 모두 숨깁니다. 이후 사이트가 지도 위에 새 UI를 얹어도 앱을 다시 고치지 않고 가려집니다.

  반대로 사이트가 지도를 그리는 층을 새로 만들면, 설정을 켰을 때 그 층까지 가려질 수 있습니다. 설정을 켰을 때만 지도 일부가 보이지 않으면 알려 주세요.

- **온라인 지도가 작게 뜨고 이동 제한이 느슨해지던 문제 수정**

  사이트가 바닥 지도를 그리는 방식을 바꾸면서, 앱이 지도의 실제 크기 대신 그림을 담는 상자 전체의 크기를 재고 있었습니다. 그 결과 지도를 처음 열 때 창보다 작게 맞춰지고, 지도를 화면 밖으로 끌었을 때 되돌리는 기준도 느슨해졌습니다. 이제 실제로 그려진 영역의 크기를 재서 맞춥니다. 크기를 잴 수 없을 때는 틀린 크기로 맞추지 않고 자동 맞춤과 위치 보정을 멈춥니다.

## 그 밖의 변경

- 자동 업데이트와 버전 선택을 처리하는 코드를 다른 앱에서도 쓸 수 있는 라이브러리로 옮겼습니다. 설정 화면의 사용 방법은 그대로이며, 실제로 설치한 앱에서 자동 업데이트, 베타 버전 받기, 이전 버전으로 되돌리기와 다시 올리기, 포터블 판 업데이트가 동작하는 것을 확인했습니다.
