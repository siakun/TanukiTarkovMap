## 주요 업데이트 내용

- **화면 언어 설정 추가 (한국어, English, 日本語)**

  설정 맨 위의 `언어 / Language`에서 앱 화면에 쓸 언어를 고를 수 있습니다. 고르는 즉시 설정 화면, 상단바와 툴팁, 트레이 메뉴, 로컬 지도의 안내 문구가 그 언어로 바뀌므로 앱을 다시 시작하지 않아도 됩니다.

  기본값은 `Windows 설정 따르기`이며 Windows 표시 언어를 따릅니다. Windows 표시 언어가 한국어, 영어, 일본어가 아니면 영어로 표시합니다.

- **업데이트 후 화면이 영어로 보이는 경우**

  위 기본값은 기존 사용자에게도 그대로 적용됩니다. 그래서 Windows 표시 언어가 영어인 PC에서는 업데이트 후 앱이 영어로 보입니다. 한국어로 쓰려면 상단바의 톱니바퀴 버튼으로 설정을 열고, 맨 위 `Language`에서 `한국어`를 고르면 됩니다.

- 온라인 지도(tarkov-market.com) 안의 문구는 사이트가 정하므로 앱 언어를 바꿔도 바뀌지 않습니다. 맵 이름과 `PMC`, `SCAV`, `Online`, `Local` 표시도 언어와 관계없이 그대로입니다.
