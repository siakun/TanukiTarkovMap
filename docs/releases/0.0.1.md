## 주요 기능

- **게임 중 확인하는 지도와 위치 표시**

  모니터 하나로 플레이할 때도 지도를 확인하려고 매번 알트탭을 하지 않도록, 창 투명도 조절과 항상 위 고정을 넣었습니다. 타르코프에서 스크린샷을 찍으면 파일명에 담긴 위치와 회전 정보를 읽어 지도에 현재 위치와 바라보는 방향을 표시합니다.

- **필요할 때만 꺼내는 지도 창**

  지도가 필요하지 않을 때는 전역 단축키로 앱을 트레이에 숨기고, 같은 단축키로 다시 표시할 수 있습니다.

- 게임과 스크린샷 폴더를 설정하고, 로그와 스크린샷의 자동 정리 여부를 선택할 수 있습니다.
- 설치형과 포터블 버전을 배포합니다. 설치형은 자동 업데이트를 지원하며, 현재 앱 버전은 설정 화면에서 확인할 수 있습니다.
