## 베타 업데이트 내용

- **릴리스 목록이 비어도 설치 가능한 버전 조회**

  GitHub가 릴리스 목록을 빈 값으로 반환하면, 배포 파일이 남아 있어도 앱의 버전 목록이 비어 이전 버전으로 돌아갈 수 없었습니다. 목록이 비어 있을 때는 태그와 각 릴리스의 배포 정보를 확인해 설치 가능한 버전 목록을 다시 구성하도록 했습니다.

- **숨긴 사이트 상단바가 다시 나타나던 문제 수정**

  화면을 꾸미는 앱의 스크립트가 상단바의 스타일을 덮어쓰면서 숨김 설정까지 지우고 있었습니다. 불필요한 덮어쓰기를 제거하고 숨김 규칙을 별도로 적용해, 페이지 요소가 다시 만들어져도 상단바가 숨겨지도록 수정했습니다.
