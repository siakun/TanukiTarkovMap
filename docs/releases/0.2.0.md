## 주요 업데이트 내용

- **원하는 버전 선택과 자동 업데이트 설정**

  새 버전에서 문제가 생겼을 때 사용자가 이전 버전으로 돌아갈 수 있도록, 설정에 버전 선택과 자동 업데이트 켜기/끄기를 추가했습니다. 최신이 아닌 버전을 선택하면 자동 업데이트도 함께 꺼서 다음 실행에서 곧바로 최신 버전으로 바뀌지 않도록 했습니다. 실험적 기능에서는 베타 버전 받기도 선택할 수 있습니다.

- **버전을 오갈 때 설정과 브라우저 데이터 보존**

  새 버전과 이전 버전이 서로 다른 위치에 설정을 저장하면서, 한쪽의 변경이 무시되거나 다른 버전에서 추가한 설정이 사라질 수 있었습니다. 파일의 수정 시각을 비교해 설정 항목별로 병합하고, 저장 도중 중단돼도 파일이 반만 남지 않도록 임시 파일을 거쳐 저장하게 했습니다. 브라우저 데이터도 복사가 끝난 뒤 저장 위치를 전환하며, 이전에 실패하면 원래 데이터를 사용하고 다음 실행에서 다시 시도합니다.

- **업데이트 다운로드가 멈춘 채 끝나지 않던 문제 수정**

  기존 시간 제한이 응답 헤더를 받는 단계에만 적용돼, 다운로드 도중 연결이 끊기면 진행률이 멈춘 채 남을 수 있었습니다. 데이터를 읽는 단계에도 시간 제한을 두고 사용자의 취소 요청을 반영하도록 바꿨습니다. 다운로드 후에는 브라우저가 사용 중인 파일을 정상적으로 닫은 뒤 업데이트를 적용하도록 종료 절차도 정리했습니다.

- **앱 제거와 캐시 정리 동작 수정**

  설정이 설치 폴더에 있어 앱을 지우면 함께 사라지고, 브라우저 캐시는 다른 위치에 남고 있었습니다. 설정은 제거 후에도 유지되는 위치로 옮기고 캐시는 제거 과정에서 정리하도록 바꿨습니다. 버전을 오가며 남은 브라우저 데이터도 용량 표시와 비우기에 포함했으며, 실행 중인 앱 때문에 제거 작업이 중복 실행으로 오인되던 문제도 수정했습니다.

## 화면과 캐시 관리

- 항상 위 고정을 꺼도 창 투명도가 적용되도록 수정했습니다.
- 설정에서 브라우저 캐시 용량을 확인하고 비우기를 예약하거나 취소할 수 있습니다. 사용 중인 파일과 충돌하지 않도록 실제 정리는 앱을 종료할 때 진행합니다.
- 설정 화면의 스크롤바와 콘텐츠 폭, 닫기 버튼의 모서리 표시를 보완했습니다.
- 설정 버튼을 톱니바퀴 아이콘으로 바꾸고 업데이트 다운로드 아이콘을 설정 버튼 왼쪽으로 옮겼습니다.

## 버전 선택 시 참고사항

- 자동 업데이트 끄기를 지원하지 않는 이전 버전으로 내려가면, 그 버전이 다시 최신 업데이트를 받을 수 있습니다.
- 포터블에서는 버전 목록을 확인할 수 있지만 앱 안에서 버전을 선택해 설치하는 기능은 설치형에서 사용합니다.
