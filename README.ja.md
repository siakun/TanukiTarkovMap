> **Escape from Tarkov 用のインゲームミニマップオーバーレイツールです。<br>スクリーンショットを撮ると座標を検出し、現在位置をミニマップに表示します。**

ゲームの上に常に表示されるウィンドウで [tarkov-market.com](https://tarkov-market.com/pilot) のインタラクティブマップを開き、ゲーム内のスクリーンショットに記録された座標から現在位置をリアルタイムで表示します。Online はサイトの地図に現在位置と向きを重ね、Local は同梱の地図に表示します。Alt+Tab をしなくても、ショートカットキー一つでマップを確認できます。

## インストール

1. [Releases ページ](https://github.com/siakun/TanukiTarkovMap/releases/latest)から最新の Setup インストーラー（`TanukiTarkovMap-Setup-<バージョン>-x64.exe`）をダウンロードします。
2. 実行してインストールすると、以降のアップデートは自動で適用されます。設定で自動アップデートをオフにしたり、好きなバージョンに戻したりすることもできます。

インストールせずに使いたい場合は、同じページからポータブル版（`TanukiTarkovMap-Portable-<バージョン>-x64.zip`）をダウンロードし、展開して実行します。ポータブル版にはインストールの手順がないため、下記の動作要件にある VC++ 再頒布可能パッケージを自分でインストールする必要があります。

> **動作要件**：Windows 10/11 (x64)、[Microsoft Visual C++ 2015-2022 再頒布可能パッケージ (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)
>
> 再頒布可能パッケージは、内蔵ブラウザー（CefSharp）が使うランタイムです。Setup インストーラーは、パッケージがなければインストールの途中で自動的に入れるので、事前の準備は要りません。手動でのインストールが必要なのはポータブル版だけです。パッケージがない状態で実行すると、`CefSharp.Core.Runtime.dll` を読み込めなかったというエラーでアプリが起動しません。
>
> **安全性**：ゲームのメモリを読んだり、ゲームのプロセスに干渉したりしません。このアプリが読むのは、スクリーンショットのファイル名（画像の内容ではなく、名前に含まれる座標だけ）と、入ったマップが記録されたゲームログの二つだけで、ゲームのファイルは変更しません。詳しい仕組みは[プロジェクトの背景](#プロジェクトの背景)を参照してください。

## 使い方

1. TanukiTarkovMap を起動します。ゲームのスクリーンショットフォルダーは自動で検出され、必要なら設定画面で指定することもできます。
2. ゲームを始めると、入ったマップに自動で切り替わります。
3. ゲーム中は、ショートカットキー（初期設定は `F11`、設定で変更可能）でマップウィンドウを表示/非表示にします。ショートカットキーでマップウィンドウを隠すのはゲームの起動中にゲームかマップウィンドウにフォーカスがあるときだけなので、マップウィンドウが表示されている間、ほかのアプリでは同じキーをそのまま使えます。隠したマップウィンドウはどのウィンドウからでもショートカットキーで再表示でき、ゲームを終了したときも自動で再表示されます（隠す操作の制限は設定の実験的機能でオフにできます）。
4. ゲーム内のスクリーンショットキー（初期設定は `PrtScn`）を押すと、Online または Local の現在位置と向きが更新されます。Online に位置表示の案内が出た場合は、上部バーで Local に切り替えてください（上部バーに表示モードがないときは、先に設定でオンにします）。

地図は初期設定では `Online` で開きます。設定の「試験的な機能」で「上部バーに表示モード（Online、Local、Origin）を表示」をオンにすると、上部バーで表示モードを選べます。`Online` は tarkov-market.com を地図中心に整理し、現在位置と向きを重ねて表示します。`Local` はアプリに同梱された地図で現在の位置と向きを表示し、`Origin` はサイトをアプリによる変更なしでそのまま開きます。`Origin` では `PMC`/`SCAV` と「UI 要素を隠す」は適用されません。選んだモードは次回の起動でも保持され、設定をオフにすると再び `Online` で開きます。

表示/非表示のショートカットキーは、ミニマップウィンドウ全体をタスクトレイに隠したり再び表示したりするもので、アプリは終了しません。位置の更新にはゲームの Screenshot キーを使います。1台のモニターでゲームの上に表示し続けるには、上部のピン（常に手前に表示）をオンにしてください。

> **Steam ユーザーへの注意**：Steam の `F12` スクリーンショットは Steam オーバーレイの機能なので、座標が記録されません。必ずゲーム本体の設定（Controls）にある Screenshot キーを使ってください。初期設定の `PrtScn` が動作しないという報告もあるため、その場合はほかのキーに割り当て直してください。

設定画面では、ショートカットキー、透明度、UI の表示、マップの自動切り替え、スクリーンショットの自動整理、アップデートの方法を変更できます。マップのタイルが溜まるブラウザーキャッシュの容量を確認して消去するのも同じ画面で行います。問題が起きたときや要望があるときは、[GitHub Issues](https://github.com/siakun/TanukiTarkovMap/issues) に投稿してください。

## 主な機能

| 機能 | 説明 |
|------|------|
| マップオーバーレイ | ゲームの上に常に表示されるインタラクティブマップ（Always-on-Top） |
| リアルタイムの位置追跡 | ゲーム内のスクリーンショットで Online と Local の位置と向きを更新 |
| 表示モード | 上部バーで Online（サイトと位置および向き）、Local（同梱の地図と位置および向き）、Origin（元のサイト）を切り替え（実験的機能、初期設定はオフ。オフのときは Online） |
| マップの自動切り替え | ゲームログを検出し、入ったマップに自動で切り替え |
| グローバルショートカットキー | ショートカットキー（初期設定は `F11`）一つでマップウィンドウを表示/非表示、修飾キーと特殊キーに対応。隠す操作はゲームかマップウィンドウにフォーカスがあるときだけ動作（実験的機能、初期設定はオン）し、再表示はどのウィンドウからでも動作 |
| レイド集中モード | レイド中、ゲームと同じモニターでマウスが触れるとマップウィンドウが反対側へ移動、そのとき Alt を押すと一時停止して操作可能、インベントリを閉じると元の位置に戻る（実験的機能、初期設定はオフ） |
| 透明度の調整 | 上部バーが隠れるとウィンドウが半透明になり、ゲームの視界の妨げを最小限に |
| UI の整理 | Online で Web ページの不要な要素を取り除き、マップだけを表示 |
| グーンズの最近の目撃情報 | PvE の目撃情報をマップに表示 |
| レイド位置共有 | 同じパーティでレイドに入ったフレンドとスクリーンショットの位置をやり取りし、マップに一緒に表示（自動接続） |
| アップデート管理 | 新しいバージョンの自動適用、自動アップデートのオフ、以前のバージョンへの切り戻し |
| 表示言語 | 初期設定は Windows の表示言語に従い、設定で選ぶと再起動なしですぐに切り替え |

グーンズの最近の目撃情報は初期設定ではオフで、設定でオンにできます。グーンズは確率でスポーンするため、情報と実際の出現場所が異なることがあります。

レイド位置共有は開発者が運用するサーバーに自動接続し、入力する値はありません。同じパーティで同じレイドに入った人同士でスクリーンショットの位置をやり取りします。ひとりで入ったレイドは共有せず、同じレイドの別のパーティは自分の位置を受け取りません。フレンドの名札は自分のゲームのパーティ通知や同じ部屋の仲間から受け取ったニックネームで表示し、見つからなければアカウント ID の末尾 4 桁で表示します。地図の左下には `InRaid: 3p (名前, 名前, 名前)` のように自分を含む共有人数と名前を表示します。スクリーンショット前も表示し、ソロ、ローカルPvE、メニュー、切断中は非表示です。

## プロジェクトの背景

Escape from Tarkov では、ゲーム内でスクリーンショットを撮ると、ファイル名にプレイヤーのワールド座標（X, Y, Z）とカメラの回転値が記録されます。開発元の Battlestate Games がバグ報告用に公式に提供している機能で、このアプリはゲームのメモリやプロセスにアクセスせず、ディスクに保存されたファイルだけを読みます。

```
2026-09-09[14-14]_179.10, 3.29, -717.65_0, 0.70710678, 0, 0.70710678_15.67 (0).png
└ 日付/時刻 ┘     └ 位置 X, Y, Z ┘      └ カメラの回転（クォータニオン） ┘
```

[tarkov-market.com](https://tarkov-market.com/pilot) の Pilot ページは、この座標を受け取ってマップ上に現在位置を表示します。ただし、ブラウザーで開く Web アプリには構造上の限界があります。ゲームの上に常に固定する（Always-on-Top）、ウィンドウを半透明にする、グローバルショートカットキーで表示を切り替えるといった、OS のウィンドウを直接制御する処理ができません。デスクトップクライアントが必要な理由はここにあります。

このようなツールはすでにいくつかあります。元祖は tarkov-market.com が公式に検出する [ggdiam/TarkovPilot](https://github.com/ggdiam/TarkovPilot)（.NET Framework、トレイ専用のヘルパー）で、韓国のコミュニティの [byeong1/Tarkov-Client](https://github.com/byeong1/Tarkov-Client) はこれを Edge WebView2 で包んでウィンドウ内に表示しました。このプロジェクトは byeong1 版のアイデアから出発しましたが、Web ビューのエンジンを CefSharp に置き換え、ウィンドウ制御、座標の同期、ビルドパイプラインを一から設計し直しました。

## 技術的な実装

このアプリはゲームのメモリやゲームファイルに手を加えず、ゲームがディスクに残すスクリーンショットのファイル名とログだけを読んで動作します。

### 1. スクリーンショットで現在位置を表示

ゲームのスクリーンショットフォルダーを監視し、新しいファイルができるとファイル名に記録された座標と視線の向きを読み取ります。画像の中身は開きません。Online ではサイトの地図の上にアプリが位置の円と向きの矢印を直接重ねて描き、Local ではアプリに同梱した地図に描きます。座標の高さから、今いる階層も自動で選びます。

### 2. サイトなしでも動く Local の地図

Local はサイトに接続せず、アプリに同梱した地図で地形と階層、選んだ陣営の脱出地点、自分の位置と向きを表示します。サイトの構造が変わって Online の表示が止まったときや、サイトに接続できないときにも、レイドに必要な情報を見られるようにしたモードです。同梱した地図はサイトの地図データを変換し、マップと階層ごとにサイトの画面と照合したもので、位置の表示はインストーラーを作るたびに自動テストで確認します。

### 3. ゲームログによるマップの自動切り替え

ゲームはレイドに入るとき、読み込んだマップをログファイルに記録します。アプリはこのログを読んで、入場したマップに地図を切り替えます。ゲームのインストールフォルダーは公式ランチャーと Steam のインストール情報から自動で見つけ、見つからない場合は設定で指定できます。レイドの途中でアプリを起動した場合も、レイド内でスクリーンショットを一度撮るとそのマップに合わせます。

### 4. ゲームの上に浮かぶウィンドウ

Web ページはゲームの上に固定したり半透明にしたりできず、ゲーム中はショートカットキーも受け取れません。このアプリは Windows のウィンドウ機能で常に手前への固定、半透明のウィンドウ、ゲーム中でも動くショートカットキーを処理し、地図はアプリに内蔵した Chromium ブラウザー（CefSharp）で開きます。

### 5. 地図だけを残す Online の画面

Online は tarkov-market.com を開き、地図を見るのに必要ないメニューやパネルを隠して、上部バーで選んだ陣営（PMC、SCAV）の脱出地点を表示します。アプリがページの中でスクリプトを実行して適用し、Origin はスクリプトを実行せずにサイトをそのまま開きます。

### 6. レイド位置共有

同じパーティで同じレイドに入ったフレンド同士がスクリーンショットの位置をやり取りし、互いの位置を地図に表示します。アプリはゲームのログから今入っているレイドとパーティを割り出し、開発者が運用するサーバーの同じルームに自動で入ります。誰かがスクリーンショットを撮ると、同じルームのほかの人にすぐ届きます。ルームはゲームがパーティとレイドごとに割り当てる値で分かれるため、同じレイドの別のパーティや配信の視聴者は入れません。

共有は付加機能なので、サーバーが止まっていたり遅かったりしても自分の位置表示はそのまま動作します。

### 7. 自動アップデートとバージョンの選択

インストールしたアプリは GitHub Releases で新しいバージョンを確認し、自動でアップデートします。新しいバージョンはアプリの起動後にダウンロードし、アプリを終了するときに適用します。変わった部分だけを受け取れる場合はその分だけをダウンロードします。新しいバージョンに問題があれば、設定で自動アップデートをオフにし、以前のバージョンに戻せます。最新ではないバージョンを選ぶと自動アップデートも一緒にオフになり、次回の起動で最新に戻りません。設定の「試験的な機能」で「ベータ版を受け取る」をオンにすると、正式リリース前のバージョンも受け取れます。

## 開発について

ビルドには Windows と .NET 10 SDK 以降が必要です。アプリは .NET 8 で動作し、ViewModel の partial プロパティ生成（`LangVersion=preview`）に最新の C# コンパイラーを使います。

```powershell
dotnet build src/TanukiTarkovMap.csproj
dotnet publish src/TanukiTarkovMap.csproj -c Release -r win-x64 --self-contained true -o publish
```

アプリのソースは `src/` にあります。座標計算、設定、ファイル監視、位置共有とサイト制御は、`src/packages/` に含まれる TanukiTarkovMap.Core パッケージが担当します。プロジェクトファイルがこのパッケージのバージョンを固定し、`src/NuGet.Config` が Core を同じフォルダーの `packages/` から、そのほかの依存関係を NuGet.org から復元するため、別途アカウントや認証は必要ありません。Core DLL は Obfuscar で難読化されており、公開 API と JSON の契約はそのままです。Releases のインストーラーは、同じタグのソースからビルドしています。
